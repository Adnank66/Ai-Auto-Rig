## 📋 Project Overview

A comprehensive web-based PC component builder application that helps users select compatible computer components and build their ideal PC configuration with real-time compatibility checking.

## 🚀 Live Demo

**Try it out**: Clone this repository and run locally
```bash
git clone https://github.com/NoTKrisHisOp/pc-builder.git
cd pc-builder
npm install
node backend/server.js
```
Then visit: `http://localhost:3000`

## 🎯 Problem Solved

**Challenge**: Building a PC can be overwhelming for beginners due to component compatibility issues, leading to expensive mistakes.

**Solution**: Created an intuitive web application that:
- Guides users through component selection
- Automatically checks compatibility
- Prevents costly compatibility errors
- Provides a smooth, educational experience
